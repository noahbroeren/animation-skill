# Craft sheets

Measured reference sheets: what good looks, moves, reads and sounds like, as numbers and rules, each mapped to the
engine parameter that controls it. The toonworld numbers come from an every-frame study of the 20 newest shorts of a
reference channel in this style (35,987 frames, 2026-11-12); the study material itself stays private.

Every sheet has the same parts, in this order:

| part | what it gives you |
|---|---|
| At a glance | the 8-12 numbers that matter most, each with how to check it |
| How it is built | the technique, step by step, in our own words |
| Rules | numbered, testable rules with ranges |
| In our engine | file, field, 1.9 value and status (built / partly / not built) |
| Check | the tool or still that shows it, and what a failure looks like |
| Common mistakes | what went wrong in our own renders, with the number and the fix |
| Sources | the study and the background research |

## The sheets

| sheet | read it when you... |
|---|---|
| `characters.md` | build or judge a cast: head, outline law, face library, limbs, torso, colour, shading on the card |
| `character-design.md` | design OUR own branded cast with `CastBrand` (what stays constant, what varies, what would be a copy) |
| `acting.md` | pose, turn and frame characters: views, expressions, blinks, mouths, gestures, walks, head size per shot |
| `camera.md` | move the camera: base push, accent moves, crash zooms, rolls, composition in 9:16, the first 3 seconds |
| `edit.md` | join shots: dissolve recipe, hidden joins, hard cuts, time jumps, pacing, endings, 12 transition recipes |
| `captions.md` | set captions: words per caption, size, position, outline, timing |
| `lighting.md` | light a scene and a story: keys per scene type and their order, practicals, window light, relights |
| `shading.md` | shade the world and the cards: cast vs form shadow, terminator, shadow hue, faces in light |
| `grade.md` | grade: black and white points, saturation, coloured darks, hue budget per scene type |
| `ink.md` | outline the world: line widths near and far, what gets inked, painted lines vs geometry ink |
| `textures.md` | paint surfaces: flat fills with thin painted lines, per material |
| `depth.md` | depth of field per shot size, haze, bloom |
| `effects.md` | add effects: the catalogue with size, duration and colour |
| `script.md` | write: the beat template with word budgets, sentence craft, hook and ending rules, picture-first writing |
| `sound.md` | narrate and mix: pace, pauses, levels, music character, sound effects |
| `hooks-titles.md` | pick a topic, hook and title (measured on 7 channels) |
| `character-types.md` | choose a kind of character (25 types, background research) |
| `general.md` | cross-style craft notes and the anti-"AI look" checklist |

The visual counterparts are in `references/sheets/` (our own renders) and in the engine's sheet projects
(`charsheet`, `setsheet`, `propsheet`).
